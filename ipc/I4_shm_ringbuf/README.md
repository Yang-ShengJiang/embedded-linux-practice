I4：共享内存 + 环形缓冲区（生产者-消费者）

功能：
利用 POSIX 共享内存（mmap）映射一块包含环形缓冲区的结构体，实现父子进程间的高速数据流传输。父进程作为生产者，子进程作为消费者，通过两个信号量（sem_empty 和 sem_full）实现严格的同步，防止读写指针覆盖和空读。

技术点：
- 结构体设计：在共享内存中必须使用定长数组（char data[]）而非指针，以避免多进程映射地址不一致导致的野指针。
- 双信号量同步：sem_empty 初始为 BUF_SIZE，控制可写空间；sem_full 初始为 0，控制可读数据。
- 环形指针回绕：读写指针通过 (pos + 1) % BUF_SIZE 实现循环。
- 资源防呆与清理：利用 atexit 注册清理函数，并结合前置 unlink 和“释放后置空”机制，确保不发生资源泄漏和二次释放。

编译运行：
gcc -o shm_ringbuf shm_ringbuf.c -lrt -pthread
./shm_ringbuf
