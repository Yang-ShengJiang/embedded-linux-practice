I2：管道通信（Pipe）

功能：
父子进程通过匿名管道（pipe）进行单向数据通信。子进程向管道写入字符串，父进程从管道读取并打印。

技术点：
- pipe：创建包含读端(pipefd[0])和写端(pipefd[1])的管道。
- 关闭多余端口：写进程必须关闭读端，读进程必须关闭写端，否则会导致 read 阻塞死等（EOF 无法触发）。
- read 缓冲区：指定正确的读取长度（sizeof(buf)），并在读取后手动添加 '\0' 结束符。
- _exit()：子进程结束后使用 _exit()，避免刷新缓冲区污染父进程。

编译运行：
gcc -o pipe_test pipe_test.c
./pipe_test
