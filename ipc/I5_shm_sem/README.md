I5：共享内存 + 信号量互斥（多进程并发计数）

功能：
利用 POSIX 共享内存映射一个共享计数器，1 个父进程和 3 个子进程并发地对该计数器执行 10000 次自增操作。通过初始值为 1 的信号量（互斥锁）保护临界区，防止多进程并发写入导致的数据踩踏（数据竞态）。最终结果精准等于 40000。

编译运行：
gcc -o shm_sem shm_sem.c -lrt -pthread
./shm_sem

技术点：
- 共享内存映射：使用 shm_open 和 mmap 映射包含计数的结构体，并用 memset 初始化为 0。
- 互斥锁实现：使用 sem_open 创建初始值为 1 的信号量。每个进程在操作 count 前后，必须严格包裹 sem_wait（加锁）和 sem_post（解锁），保证同一时刻只有一个进程进入临界区。
- 进程管理：通过 fork 创建 3 个子进程，父进程与子进程共同参与竞争。父进程使用 wait 阻塞回收所有子进程。
- 资源清理：利用 atexit 注册统一的清理函数，严格遵循“释放后置空”原则，避免文件描述符和共享内存泄漏。

测试结果：
- 正常运行：终端输出“最终结果: 40000”。
- 极端测试（去掉互斥锁）：如果注释掉 sem_wait 和 sem_post，最终结果会远小于 40000（例如 28000 左右），真实复现并发覆盖导致的错误，验证了互斥锁的必要性。
